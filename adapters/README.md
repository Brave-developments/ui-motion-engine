# Source application adapters (planned)

Do not put source website code here by copying proprietary files. Adapters may hold **imports/paths/config only** and read-only fixture mapping to a separately checked-out, user-authorized source.

For the first pilot, identify the actual FiveM Hub card component before creating a concrete adapter. `examples/component-adapter.tsx` is an illustrative contract; the file path is intentionally **not** invented.

Adapters must record: repo+commit, actual source path, providers, CSS/fonts/assets, permitted read-only data snapshot, imported React version, tested parity screenshot and render warnings.
